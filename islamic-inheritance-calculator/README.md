# برنامج حساب المواريث الشرعية الإسلامية
# Islamic Inheritance Calculator

برنامج متكامل لحساب الأنصبة الشرعية للورثة وفقاً لأحكام الشريعة الإسلامية.

## المميزات / Features

- ✅ حساب الأنصبة لجميع الورثة (أبناء، بنات، زوج/زوجة، والدين، إخوة، إلخ)
- ✅ معالجة الحجب (الكامل والجزئي)
- ✅ معالجة العصبة بالنفس والغير
- ✅ معالجة حالات العول (زيادة السهام)
- ✅ معالجة حالات الرد (نقص السهام)
- ✅ إخراج تقرير مفصل بالتوزيع
- ✅ واجهة ويب سهلة وجميلة
- ✅ دعم كامل للغة العربية والإنجليزية

## التثبيت / Installation

لا يتطلب البرنامج تثبيت مكتبات خارجية. فقط افتح ملف `index.html` في المتصفح.

## الاستخدام / Usage

### واجهة الويب
افتح ملف `public/index.html` في المتصفح

### سطر الأوامر (CLI)
```bash
npm start
```

### كمكتبة (Library)
```javascript
const InheritanceCalculator = require('./src/inheritance-calculator');

const heirs = {
  husband: true,
  sons: 2,
  daughters: 1,
  father: true,
  mother: true
};

const estate = 100000;
const result = InheritanceCalculator.calculate(heirs, estate);
console.log(result);
```

## الأساس الشرعي / Islamic Legal Basis

البرنامج مبني على أحكام المواريث من القرآن الكريم والسنة النبوية:

- **سورة النساء (آية 11)**: أحكام ميراث الأولاد والوالدين
- **سورة النساء (آية 12)**: أحكام ميراث الزوجين والإخوة
- **سورة النساء (آية 176)**: أحكام الكلالة

## المصطلحات / Terminology

- **الفروض**: الأنصبة المقدرة شرعاً (النصف، الربع، الثمن، الثلثان، الثلث، السدس)
- **العصبة**: من يأخذ الباقي بعد أصحاب الفروض
- **الحجب**: منع الوارث من الميراث كلياً أو جزئياً
- **العول**: زيادة مجموع السهام عن أصل المسألة
- **الرد**: نقص مجموع السهام عن أصل المسألة
